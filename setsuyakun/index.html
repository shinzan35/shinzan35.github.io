プライバシーポリシー

制定日: 2026年8月30日

1. 基本方針

本アプリの運営者（以下「当社」といいます）は、ユーザーのプライバシーを尊重し、お客様の個人情報の保護に努めます。本プライバシーポリシーは、本アプリにおける情報の取扱いについて定めるものです。

2. 写真・動画の処理に関する重要なお約束（端末内処理）

  • 本アプリにおける写真・動画のサイズ変更、圧縮、編集その他の処理は、原則としてユーザーの端末上（ローカル）で実行されます。
  • 写真・動画ファイルそのものを当社が運営する外部サーバーへアップロード、保存、解析または収集することはありません。
  • 本アプリによって処理される写真・動画の内容を、広告配信、分析、マーケティングその他の目的で当社が取得・利用することはありません。

3. 広告配信および第三者サービスによる情報の処理

本アプリでは、サービスを継続・提供するため、以下の第三者サービス（広告配信・解析等）を利用する場合があります。

  • Google Mobile Ads SDK (Google AdMob)
  • Firebase Analytics / Crashlytics

これらの第三者サービス提供者は、広告の配信、頻度制御、不正行為の防止、クラッシュレポートの収集、サービスの安全性確保等の目的で、IPアドレス、端末・OS情報、広告識別子（IDFA / Advertising ID）その他の技術的情報を自動的に処理する場合があります。

※当社が広告事業者等へ写真・動画そのものを提供・送信することはありません。また、本アプリにおいて当社がクロスアプリ・クロスサイト・トラッキングを目的とした独自の追跡を行うことはありません。

4. データの保存・削除・復元について

  • 当社が運営するサーバー等に写真・動画データが保管されることはありません。
  • ユーザーが本アプリを利用して端末上のデータを削除する場合、その操作はユーザー自身の選択および確認に基づいて端末上で実行されます。
  • 本アプリ自体には、削除されたファイルを復元する機能はありません。ユーザーは、重要なデータについて事前に適切なバックアップを取得する責任を負います。
  • 端末のOS、クラウドサービス、外部ストレージ等による保存・復元機能については、本アプリの管理対象外です。

5. 第三者への提供

当社は、法令に基づく開示請求を受けた場合、裁判所・行政機関等の公的機関から適法な要請を受けた場合、または人の生命・身体・財産の保護のために必要な場合を除き、保有する情報を第三者に販売・提供しません。

6. 国際的なプライバシー権への配慮

本アプリは日本国内のみならず、海外のユーザーによって利用される場合があります。当社は適用される法令（GDPR、CCPA等の各地域法を含みます）の趣旨を尊重し、ユーザーが有する法的な権利（アクセス、訂正、削除等）の行使に関するお問い合わせに対して適切に対応します。

本ポリシーのいかなる規定も、ユーザーが居住する国または地域の強行法規により認められる消費者の法的権利を制限するものではありません。
