🇯🇵 Spot data file — data.html

This file stores every spot used by index.html: 9 regions × 47 prefectures × 7 genres, each with English / Japanese names, descriptions, an official website (or a reference link such as a Tabelog search) and a Google Maps search keyword.

The food category is split into 16 styles (kaiseki, sushi, shojin, unagi & river fish, honzen, Chinese, ramen, B-class gourmet, tempura, sukiyaki, yakiniku, gyoza, udon, soba, tonkatsu, steak) and the shopping category includes supermarkets. Styles that do not exist in a prefecture are simply not listed.

Temples and shrines (社寺) are intentionally excluded from this dataset.

Open index.html to browse the guide. This data file is also read directly by index.html — either as a classic script or by handing the data over through the browser — so the app works even when the files are opened straight from a desktop folder.
